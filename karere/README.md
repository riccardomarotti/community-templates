# Karere

Themes the WhatsApp Web interface inside Karere using the current Noctalia palette.

Requires a Karere version with custom web CSS support and live stylesheet reload.

Generated stylesheet paths:

- Native: `$XDG_CONFIG_HOME/karere/custom.css`
- Flatpak: `~/.var/app/io.github.tobagin.karere/config/karere/custom.css`

Karere reloads the stylesheet automatically when Noctalia updates it. The template is
compatible with both dark and light Noctalia palettes.
